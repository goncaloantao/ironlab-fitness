# IRONLAB Fitness 🏋️

Website moderno e responsivo desenvolvido para um ginásio fictício, com foco numa imagem forte, navegação simples e conversão de visitantes através de pedidos de aula experimental por WhatsApp.

## 🌐 Demo
https://ironlab-fitness.netlify.app/

## ✨ Funcionalidades

- Página inicial com apresentação do ginásio
- Secção de serviços
- Planos e preços
- Apresentação da equipa
- Testemunho demonstrativo
- Formulário para aula experimental
- Envio automático do pedido através do WhatsApp
- Contactos e horários
- Botão flutuante de WhatsApp
- Menu responsivo para dispositivos móveis
- Design adaptado a computador, tablet e telemóvel
- Navegação suave entre secções

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Netlify

## 📱 Responsivo

O website foi desenvolvido para funcionar corretamente em diferentes tamanhos de ecrã, incluindo computador, tablet e smartphone.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido como parte do meu portfólio, com o objetivo de criar uma solução moderna e funcional para ginásios, personal trainers e negócios ligados ao fitness que pretendam melhorar a sua presença online e facilitar o contacto com potenciais clientes.
